# acttub-frontend

Acttub frontend application built with Next.js, React, TypeScript, Tailwind CSS, shadcn/ui, and TanStack Query.

## Development

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```
